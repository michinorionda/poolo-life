Mobile First — A / B / C

スマホで、迷わず
申し込めるように。

鞆の浦・走島 1泊2日のLPを、スマホで見やすく・申し込みやすくすることだけを目的に3通り組み直しました。掲載する事実は既存LPと同じ。変えたのは構成・情報量・導線・操作方法です。

読み手はほぼ全員スマホ（Instagram / LINE / X からの流入）。片手で、電車の中で、数十秒だけ見る。その条件で申し込みまで運べるかを唯一の評価軸にしています。

3案とも 390px（iPhone 14/15）の実寸で計測済み。横スクロールの発生、タップ領域、文字サイズ、追従CTAの出現までを機械的に検査しています。

01

まず、数字で見る

いちばん効くのはスクロール量です。既存のPC起点LPをそのままスマホで開くと、下まで26,000px以上ある。指で20回以上スワイプしないと申込ボタンに届きません。3案はここを解きにいっています。

A一本道スクロール
やったこと
15セクションを8つに統合。notice-bar／4つのPoint／Before→After／向き・不向き／About POOLO を落とし、「なぜ鞆の浦」と「暮らし観光」は1本にまとめた。FAQは9問→5問、人物略歴は2文、スケジュールは時刻＋タイトルのみ。
強いところ
操作の学習コストがゼロ。開く・送るがなく、下に進むだけ。読み手がどこにいるか常に分かる。3案でいちばん実装がシンプルで、崩れる余地が少ない。
弱いところ
情報が実際に減っている。とくに「向き・不向き」と Before→After を落としたぶん、期待値のずれた申込を止める力が弱い。答えを約束しない企画なので、ここは効いていた部分。
B折りたたみ／全部読ませない
やったこと
ネイティブの <details> を24個。旅の趣旨・プログラム・登壇者・費用内訳・FAQ をすべて閉じた状態で置き、<summary> は「見出し＋一言要約」の2行にして、閉じたまま目次として読めるようにした。ヒーロー直下に「日程／場所／参加費／定員・締切」の常設欄。
強いところ
情報を削らずにスクロールが最短（6,115px＝既存の23%）。閉じたまま「いつ・どこ・いくら・どう申し込む」が完結する。<details> はネイティブ要素なので、キーボード操作もスクリーンリーダーもそのまま効く。
弱いところ
開かないと中身に到達しない。読み手が「開く」操作をしてくれる前提に乗っている。全部開くと結局長い。本文中のリンク5件がタップ領域29px。
Cカード／横スワイプ
やったこと
並列な情報（3ステップ・4つのこと・出会う人3人・DAY1の7項目・DAY2の8項目）を計25枚のカードにして、5つの横スワイプに逃がした。CSSの scroll-snap のみで実装し、位置表示のドットだけJS。費用・日程・申込は縦の導線に残してある。
強いところ
指で送る操作が気持ちいい。InstagramやNetflixに慣れた層には自然。スワイプしなくても重要情報には到達できる設計になっている。860px以上ではグリッドに組み替わる。
弱いところ
全高18,542px と3案でいちばん長い。横に逃がしたぶん縦が減るはずが、カードの余白で相殺されている。また、送らなかった人はカードの2枚目以降を見ない。

推奨：案B（折りたたみ）。ただし案Aの削る判断を一部持ち込む。

「スマホで見やすい・申し込みしやすい」が第一優先なら、案Bを推します。決め手は、情報を削らずにスクロールを77%減らせていることです。案Aも軽いのですが、軽さの理由が「内容を落としたから」なので、後から「やっぱりこれも載せたい」となったときに一本道が長くなって元に戻ります。案Bは畳んであるだけなので、載せる量が増えても閉じた状態の長さはほとんど変わりません。

加えて、この企画は答えを約束しないという性格上、期待値のずれた申込を減らす情報（向き・不向き、Before→After、費用の内訳）を落としたくない。案Bならそれらを畳んだまま持てます。

そのうえで、案Aから「FAQを9問から絞る」「人物略歴を2文にする」という判断は持ち込む価値があります。畳めるからといって全部載せると、開いた人が疲れます。

案Cは、写真が揃ってから再評価したい案です。いまは暫定写真なのでカードの魅力が出きっていません。鞆の浦のまち並み写真が入ると、印象がかなり変わる可能性があります。

03

決めたあとにやること

  • 案を1つ選ぶ（または案Bベース＋案Aの削り方、というハイブリッドを指定する）
  • 選んだ案を event-tomonoura/index.html に統合する（PC表示も含めて1本にする）
  • 実機で触って確認する（iPhone実機での追従CTAの出方、<details> の開閉、横スワイプの感触は、実機でしか分からない）
  • 申込フォームURLを入れる（現在すべて href="#"）
  • 鞆の浦のまち並み写真に差し替える（3案とも暫定写真のまま）
  • noindex を外す
