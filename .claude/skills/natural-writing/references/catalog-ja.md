# 日本語の「AI っぽさ」兆候カタログと打ち消し方

2024〜2026 年の日本語圏の実務家（もとやま、だいち、munyoru、coji、nakashimatakaya ほか）の観察と、それを実装した lint（textlint-rule-preset-ai-writing、natural-japanese、deslop-ja、humanizer-ja、stop-ai-slop-jp）から集めた。出典は `sources.md`。

重要な前提：**単発では判定しない。密度と併発で見る。** 「最後に」「まさに」「一方で」「結論から言うと」は人間の常用語で、消すと逆に不自然になる。

---

## 1. 語彙

| 分類 | 兆候 | 打ち消し方 |
|---|---|---|
| 意義づけ・評価語 | 重要な／不可欠／鍵となる／注目を集めている／浮き彫りにする／画期的／革新的／多面的／包括的／重要な示唆／〜を物語っている／〜と言っても過言ではない | 事実と数字に置き換える。「極めて重要」→「申請が 3 日から 4 時間に縮んだ」。意義は読み手が決める |
| 誇張 | 革命的／ゲームチェンジャー／究極／完全に解決／可能性を解き放つ／民主化／再定義／パラダイムシフト／次世代 | 全部削る。残った文で足りるか見る |
| 定型導入 | 近年／昨今／〜が注目されています／本記事では〜を解説します／〜をご存知でしょうか／結論から言うと／以下の 3 つの観点から／まず・次に・最後に | 一行目から本題。導入は書かない |
| 定型締め | いかがでしたか／まとめると／以上より／今後の展開が注目されます／〜が期待されます／ぜひ〜してみてください／参考になれば幸いです | 最後の具体で終える。まとめを書かない |
| 曖昧な権威づけ | 〜と言われています／専門家によると／多くの人が／〜とされています | 誰が言ったか書く。書けないなら主張を消す |
| 2026 年に急増した AI 偏愛語 | 解像度／手触り／泥臭さ／本質／営み／文脈／熱量／静かな（quiet の輸入）／〜が効く／〜が刺さる／〜が死ぬ | 中身を書く。「解像度が上がる」→ 何が見えるようになったか |
| 壮大化・比喩テンプレ | 真理／宿命／境地／羅針盤／北極星／架け橋／土台／エンジン／〜という旅／〜の世界が広がる／〜への第一歩 | 題材から出た比喩をひとつだけ使い、二度以上出して回収する |
| 冗長・翻訳調 | 〜することができます／〜を活用する／〜を行う／〜という点において／〜といった／〜を通じて／〜において／カタカナ語の連打（レバレッジ、アライメント、コンテキスト） | 「〜できる」「〜する」。カタカナ語は和語へ |

## 2. 文末・ヘッジ

| 兆候 | 例 | 打ち消し方 |
|---|---|---|
| 断定回避 3 兄弟 | 〜と言えるでしょう／〜ではないでしょうか／〜と考えられます | 言い切るか削る。言い切れないなら「〜の場合は〜」と条件で書く、または【要確認】 |
| 予防線 | 一概には言えませんが／個人差がありますが／〜という側面もあります | 消す。反論が必要なら「ただし」で一文 |
| 結論回避 | ケースバイケース／メリットもあればデメリットも／それぞれの良さがあります | 書き手の判断を書く。間違いうる主張をひとつ |
| 弱い否定 | あまり推奨されません／注意が必要です | 「やめたほうがいい」「壊れる」と書く |
| 均一な敬体 | です・ます が 3 文以上連続 | 体言止め、「〜てみる」「〜のこと。」、問いを混ぜる。ただし敬体・常体の混在は文書内で統一 |
| 敬体の地の文にキメの常体 | 「差はここで付く。」を段落末に差し込む | 消す。格言化しない |
| チャットの残骸 | 素晴らしいご質問ですね／おっしゃる通り／その認識は正しいです／良ければ〜も教えますよ | 全削除 |

## 3. 構文

| 兆候 | 例 | 打ち消し方 |
|---|---|---|
| 「これにより」 | 日本語 AI 文の最大マーカー。1 回でも直す | 因果を主語と動詞で書く |
| 接続詞の機械的追加 | 一方で／さらに／加えて／また／だからこそ／つまり を文頭に | 順接は 8 割消せる。「一方で」は反論があるときだけ「ただし」 |
| 否定→肯定の対比 | 単なる A ではなく B／A でも B でもなく C／理由は A ではありません。B だからです | B だけ書く。人間の使用率は文の 1.5%、AI は 8.3%（coji の 406 本計測） |
| 三項並列 | 3 つのポイント／学び、つながり、そして発見 | 実数に戻す。2 つなら 2 つ、5 つなら 5 つ |
| 無生物主語 | データが示している／文化が醸成される | 主語を人に戻す |
| 付け足しの分詞構文 | 事実＋〜しており、〜を示している | 後半を消すか、出典つきの別文に |
| 自問自答 | なぜ〜なのか？ で始めて即答える／想像してみてください | 問いはひとつ、答えは書く。残りは平叙文 |

## 4. 構造・記号

| 兆候 | 打ち消し方 |
|---|---|
| 見出し乱発（300 字以下の節に H3）、命題型 H2、コロン副題 | 散文に戻す。見出しは章にだけ |
| 太字＋コロン箇条書き（**速度:** 3 倍）、絵文字見出し、`**` 残骸、コロン後の半角スペース、全角ダッシュ ——、日本語を "" で囲む | 散文か平文リスト。ダッシュは（）か読点。絵文字は全削除 |
| 段落が全部 3〜5 文で揃う、章の分量が均一、段落の閉じ方が毎回きれい | 文数と文長を意図的に崩す。1 文段落を置く。重い章は厚く、軽い章は軽く |
| 体言止めゼロ（随筆の人間の書き手の 6 割が使う）、または連打して標語化 | 2〜3 割 |
| 文長の変動係数が低い（バースト性がない） | 4 字の文と 80 字の文を同じ段落に。7 モデル×406 本の実測で、語彙より文長・段落の均一さが全モデル共通の癖として残る |
| 段落を入れ替えても成立する（トレッドミル） | 前の段落の最後の具体を次の段落が受ける |

## 5. トーン・内容

| 兆候 | 打ち消し方 |
|---|---|
| 書き手の不在。間違いうる具体的な主張へのコミットがない | 見出しごとに固有名詞か実数を最低ひとつ。失敗・迷い・恥ずかしい数字を入れる |
| 感情の温度が一定 | 「悪くない」「微妙」「まだわからない」を混ぜる |
| 「わたし」がいない。その人が書く理由がない（古賀史健×田中泰延） | 書き手と理由を先に決める |
| 誤字がなく、文法が完璧で、網羅的 | 網羅しない。書き手が知っていることだけ書く。誤字はわざと入れない |
| 伝聞がない | 「らしい」「と聞いた」を残す。ただし一人称の体験は捏造しない |

## 6. コピー・LP・告知文の常套句

**危険語**：寄り添う／伴走／課題解決／最適化／シームレス／唯一無二／業界初／お客様第一／〜を実現します（連発）／価値を提供／想いをカタチに／珠玉の／彩る／切り拓く／化学反応／時代が到来／絶景／満喫／人気観光地／人生が変わる／市場価値

**構文**：それだけではありません／〜の世界へようこそ／新しい自分に出会う／一歩踏み出す／仲間と共に／かけがえのない／心に響く／〜な体験をお届け／あなたの〜を応援

**判定法：競合置き換えテスト**。POOLO を他社名・他イベント名に差し替えても成立するコピーは、誰にでも書ける文。「学び・つながり・発見」→「講演とパネルがあり、休憩時間に参加者同士で話せる」。

**約束しない**：「やりたいことが見つかる」「キャリアが決まる」（鞆の浦 LP の依頼書より）。

## 7. 名文家の助言との接続

- 谷崎潤一郎『文章読本』：饒舌を慎む。言葉を削る。文法に囚われない。分かりやすい語を選ぶ。
- 本多勝一『日本語の作文技術』：読点は「長い修飾語の境界」と「語順が逆のとき」に打つ。長い修飾語を先に置く。
- 井上ひさし：むずかしいことをやさしく、やさしいことをふかく。
- 古賀史健：文章はリズム。主張・理由・事実。
- 田中泰延：調べることは愛。一次資料に当たる。
- 糸井重里×東浩紀：AI には「やっちまったなぁ」（経験）がない。

## 8. 工程

1. 生成時に制約する（この CLAUDE.md と SKILL.md）。事後修正より効く。
2. 機械検出（`scripts/check.py`、textlint preset-ai-writing）で候補を出し、判断は人。
3. AI 文を 5 分の 1 に圧縮してから具体例を挿入する（tinect）。
4. 音読テスト・削除テスト。
5. 検出ゼロを目標にしない。
