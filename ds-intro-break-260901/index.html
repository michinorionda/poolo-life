.intro-break を廃止しました。

導入本文のなかで一文だけを大きく見せる装置（「ただ、しかし。」など）を、デザインシステムから削除しました。本文の途中に強調のための組版装置を置かない。これを新しい方針とします。転換は組版ではなく、文章で示します。2026年9月1日。

DSカタログ 鞆の浦LP 東川・冬LP
01

なぜやめたか

BRAND.md には「転換は一言で、間を作る」と書かれており、.intro-break はそのための装置でした。明朝28px・左に34pxのブランドブルーの罫・大きめの級数。

実際には、2つの問題がありました。

1つめ。間を作れていませんでした。 .intro-break は自分の余白を一行も持っておらず、直前の .intro-body p { margin-bottom: 2.1em } ＝ 普通の段落とまったく同じ間隔で置かれていました。間を作ると決めているのに、間を作る指定がどこにもなかった。

2つめ。そもそも装置が要りませんでした。 導入本文の途中で一文だけを大きく見せると、読み手にはそれが転換ではなく小見出しとして届きます。左の罫は .hero-eyebrow-rule や .pb-caption-rule と同じ「ラベルのあしらい」なので、なおさらです。結果として、文章が読み進められるべきところで一度切れてしまう。

間の取り方を変える案（余白／ヘアライン／右寄せ）も検討しましたが、装置そのものを外すのが正解でした。転換は、文章の力で示せます。

本文の途中に、強調のための組版装置を置かない。
転換は「ただ、」「けれど、」と書いて、普通の文章として読ませる。
02

変更前と、変更後

Before 以前の見え方 明朝28px ＋ 左罫34px ／ 一文だけが独立している
01
Concept

瀬戸内海の暮らしから、
キャリアを考えてみる。

これからのキャリアを考えるとき、多くの人は転職サイトを開いたり、自己分析のシートを埋めたりします。それも、もちろん有効な方法のひとつです。

ただ、しかし。

「どんな仕事をするか」だけを考えていても、答えが出ないことがあります。これからを決めているのは、仕事の条件だけではないからです。そこまで含めて、はじめて「これから」の話になる。
