POOLO Design System — Component Review

転換の一言を、どう置くか。

.intro-break（「ただ、しかし。」のような、導入本文のなかで話が折り返す一言）の再設計。BRAND.md は「転換は一言で、間を作る」と書いていますが、いまの実装は間を作っていません。原因の特定と、3つの案、推奨をまとめています。2026年9月1日。

DSカタログ 使用例：鞆の浦LP
01

いま何が起きているか

BRAND.md の 2章（声のトーン）には、こう書いてあります。

転換は一言で、間を作る。「ただ、しかし。」のような一言を .intro-break（明朝・罫つき・大きめ）で独立させる。

ところが components.css の .intro-break は、自分の余白（margin）を一行も持っていません。そのため直前の .intro-body p { margin-bottom: 2.1em } ＝ 普通の段落とまったく同じ間隔で置かれます。「間を作る」と決めているのに、間を作る指定がどこにもない状態でした。

代わりに効いているのは、文字を大きくすること（28px）と、左に34pxのブランドブルーの罫を足すことの2つです。この罫は .hero-eyebrow-rule や .pb-caption-rule と同じ「ラベルのあしらい」なので、読み手には転換ではなく、小見出しのラベルとして届きます。少し大きい行が、同じ左端に、同じ間隔で並んでいるだけ。だから立ち止まれません。

意図（BRAND.md）話が折り返す。読み手をいったん止める。
実装（components.css）級数を上げる ＋ 左に罫。余白の指定なし。
ずれ「間」は級数や装飾では作れない。何もない領域の大きさでしか作れない。
Current いまの実装 明朝28px ＋ 左罫34px ／ 余白は本文と同じ 2.1em

02

大元の考えを、どう更新するか

POOLO の視覚言語は、いま4つの手を持っています。ブルーのベタ面、1pxのヘアライン、級数コントラスト、非対称マガジン。どれも「置く」ための手です。足りていないのは、置かないための手でした。

そこで、視覚言語に5つめを足します。

間は、装飾ではなく不在で作る。
転換は「何かを足す」のではなく、「その周りを空ける」ことで示す。

この考えに立つと、.intro-break に必要なのは罫ではなく余白の所有権です。段落の2.1emではなく、自分の間隔を自分で決める。以下の3案は、空け方の方向を変えたものです。いずれも左の装飾罫は落としています（ラベルのあしらいと混ざるため）。

03

3つの案

Plan A 間（ま） 余白だけで断つ ／ 推奨

装飾をすべて外し、上下に段落の約3倍（最大112px）の余白を与えます。級数はわずかに上げ、字間を 0.22em → 0.3em に開く。足すものは何もなく、空けるだけ。「装飾過多を避ける」というPOOLOの原則に、いちばん素直です。前後の段落が自然に切り離され、一言だけが宙に浮きます。

04

推奨は A（間）

A を推します。理由は3つあります。

1. 原因に直接効いている。問題は「余白がないこと」でした。Aはそこだけを直しています。BとCは余白に加えて罫や配置も足しており、直っているのは同じ一点です。

2. 約35ページに一斉に効く。この変更はDSのシングルソースに入るので、既存の全告知ページの導入部が同時に変わります。Aは既存の見え方を壊しません（余白が増え、罫が消えるだけ）。Cの右寄せは、ページによっては前後の文脈と噛み合わない可能性があります。

3. 「装飾過多を避ける」に忠実。BRAND.md が繰り返し言っているのは引き算です。転換の表現として何かを足すより、何も足さないほうが POOLO らしい。

Cは魅力的ですが、汎用コンポーネントではなく、ここぞという1ページの変種として持つのが適切だと考えます。必要なら .intro-break--aside のような修飾クラスで足せます。

05

実装と、波及範囲

poolo-ds/components.css の .intro-break を差し替えます。セレクタを .intro-body .intro-break にしているのは、.intro-body p（クラス1＋要素1）より詳細度を上げて、余白を確実に自分のものにするためです。

.intro-body .intro-break { font-family: var(--mincho); font-weight: 700; font-feature-settings: "palt"; font-size: clamp(23px, 3vw, 31px); letter-spacing: 0.3em; color: var(--ink); line-height: 1.4; /* 間は装飾ではなく不在で作る。段落の 2.1em ではなく、自分で持つ */ margin-top: clamp(64px, 9vh, 112px); margin-bottom: clamp(64px, 9vh, 112px); } /* 左の装飾罫は廃止（.hero-eyebrow-rule 等のラベル語彙と混ざるため） */ .intro-break::before { content: none; }
波及.intro-break を使っている告知ページ 約35ページの導入部。いずれも「間が広がり、左の青い罫が消える」変化で、レイアウトは崩れません。
