ヒーローの数字を、どう組むか

最初の案（A）は Jost の 600 を 1.16em で置いていました。Jost は幾何学サンセリフで、0 は真円、9 は円と直線。Zen Old Mincho は縦画が太く横画が細い明朝で、同じ行に並べると片方だけ抑揚がゼロになります。大きくしているぶん、その平たさがよけいに見えました。以下は組み方の比較です。数字以外の値（級数・字間・行送り）は告知ページと同じにしてあります。

採用したのは C（明朝・1.32em・字間 −0.02em）。2026-09-08 に5本へ反映しました。書体を変えずに級数と字間だけで差をつけています。明朝の数字は縦画が太いので、大きくすれば和文より重くなり、それだけで数字が主役になります。
BRAND.md の「欧文・数字は Jost」は、日付帯やラベルのように欧文が単独で立つ場所の話で、明朝の見出しの内側には持ち込まない、という整理にしました。

AJost 600・1.16em（いまの案） 欧文と和文が直交して数字は立つ。ただし明朝の抑揚に対して数字だけ monoline なので、値札を貼ったように見える。
30代の生き方を問い直す90分。

font-family: Jost / weight 600 / 1.16em / tracking .01em

D何もしない（素の明朝） 比較用の基準。明朝の数字は和文と同じ骨格なので破綻はしないが、数字が図として立たない。
30代の生き方を問い直す90分。

指定なし（Zen Old Mincho・weight を継承）

B明朝のまま・級数だけ 1.14em 書体を変えず、大きさだけで差をつける。抑揚が揃うので線が濁らない。差は小さい。
30代の生き方を問い直す90分。

Zen Old Mincho / weight 継承（900）/ 1.14em

C明朝・1.3em・字間を詰める B をもう一段強くした案。明朝の数字は縦画が太いので、大きくすると和文より重くなり、数字が主役になる。
30代の生き方を問い直す90分。

Zen Old Mincho / weight 900 / 1.3em / tracking −.02em

G明朝・1.34em・和文側の字間も詰める C の字間を全体で締めた案。数字と和文が一続きの塊になり、「90分」がひとつの語として読める。
30代の生き方を問い直す90分。

Zen Old Mincho / weight 900 / 1.34em / 数字 −.03em・和文 .01em

EJost 300・1.34em（細く・大きく） 欧文を残したい場合の案。太さを 600→300 に落として明朝の細い横画に寄せ、そのぶん大きくする。
30代の生き方を問い直す90分。

font-family: Jost / weight 300 / 1.34em

F明朝・1.3em・数字をブランドブルー C の色違い。ブルーを「問い直す」から数字に移している（同じ行にブルーは1箇所までなので、両方は置けない）。
30代の生き方を問い直す90分。

Zen Old Mincho / weight 900 / 1.3em / color: --brand
