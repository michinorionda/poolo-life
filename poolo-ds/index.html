明朝の顔で。

POOLO（by TABIPPO）のイベント告知ページを、コピペではなく単一ソースで組み立てるためのコンポーネントカタログです。新しいページは tokens.css と components.css を読み込み、下のマークアップを写して作ります。主役はブランドブルー #189BBC。フラットなベタ面とヘアラインで構成し、大見出しの顔は明朝（Zen Old Mincho）が担います。

プログラムの3ステップ.program-steps / .program-step(.is-main) / .ps-num / .ps-tag / .ps-title / .ps-desc / .ps-meta単発イベントではなく「前後を含む一連のプログラム」であることを見せる縦フロー。主役の回は .is-main で淡ブルー面に。
  1. Step 01オンライン

    旅に出る前から、旅は始まる。

    現地で何を見たいのか。自分は何について考えてみたいのか。問いをひとつ持って出発します。

    実施：オンライン ／ 日時：[後日決定]

  2. Step 02現地・1泊2日

    暮らしのなかへ、入っていく。

    その土地で働き、暮らしている人の話を聞く。歩く。話す。ひとりで考える。

  3. Step 03オンライン

    旅を、日常と切り離さない。

    持ち帰った問いを、もう一度みんなで話す。日常で試してみたいことを、ひとつ決めます。

体験の要点（4つ）.point-list / .point-item / .point-num(.no) / .point-title / .point-desc「この体験で得られる4つのこと」を2列で。番号は Jost、見出しは明朝。
  1. Point01

    さまざまな働き方・生き方をしている人に会う

    正解を教えてもらうのではなく、実際にその土地で人生を営んでいる人から話を聞きます。

  2. Point02

    観光ではなく、「暮らし」を旅する

    商店、路地、人との会話。その土地の日常のほうへ入っていきます。
