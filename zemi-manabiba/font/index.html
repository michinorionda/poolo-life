POOLOゼミ「学びの場を、創る。」のためのディスプレイ数字書体です。日付・価格・定員・回数——告知でいちばん多く出る数字を、既製の欧文書体ではなく自前の字で持つために設計しました。

Rules

4つの設計規則

飾りから入らず、ゼミの思想を字形の規則に翻訳するところから始めました。読めなくなる手前で止めています。

01閉じた形の天に、開口をつくる

0・6・8・9の環は、右上でわずかに開いています。閉じきらないことを、書体そのものの約束にしました。

02縦は太く、横は細く

明朝の骨格を数字に持ち込んでいます。POOLOの見出し（Zen Old Mincho）と並べたときに、太さの呼吸が揃います。

03終端は、進行方向へ斜めに切る

1の足、2・5・7の横画。水平に切らず、わずかに倒しています。止まっていない感じを出すためです。

04数字はすべて等幅

日程表・価格・定員を縦に積んだとき、桁が揃います。実務で使う書体なので、ここは譲れません。

How to use

使い方

ウェブページに読み込む

@font-face {
  font-family: 'POOLO Zemi Toi';
  src: url('/poolo-life/zemi-manabiba/font/PooloZemiToi-Display.woff2') format('woff2');
  font-display: swap;
}
.bigdate { font-family: 'POOLO Zemi Toi', var(--en); }

Illustrator / Figma / Keynote で使う

PooloZemiToi-Display.otf をダウンロードしてダブルクリック、macOSのFont Bookでインストールすれば、どのアプリからも「POOLO Zemi Toi」として選べます。

SNS素材のスクリーンショットにもそのまま反映されます。
