打診の背景

POOLOメンバーでノマドニアに参加しているメンバー、ノマドニアメンバーでPOOLOに参加しているメンバーも最近増えてきているので、ルイスにゲストに出て貰えるとお互いにいいんじゃないかなと思って、今回打診をさせて貰いました。

具体的な内容＆背景は下記です。

とにもかくにも「集客」はどんな人もぶち当たる壁だと思っています。

ノマドニア、スラッシュワーカーズと、新しいサービスをゼロから立ち上げ続けてきたマーケ・集客の考え方をぜひ、参加者にインプットしてほしいなと思っての相談です。

もし、ルイスがゼミを企画するとしたら、どんなことを一番大事に考えて集客をするのか。コンセプト作り、参加者のインサイトの掴み方、SNSの運用、LPのサイト、コピー等々。

そして、表には出てこない泥臭い作業もあったはずなので、そこをぜひ話して貰えると嬉しいなと思っています。うまくいった話だけでなく、人が集まらなかった時に何をしたのか、何を考えていたのかを聞けたら嬉しいです。

全7回の流れ

問いを掘る → 学びにする → 設計する → 試作する → 磨く → 集める → 創る。隔週・各120分で、最終回には自分のゼミを開ける状態になります。第3回と第6回が、外部ゲストをお招きする講義回です。

  1. 10/13（火）｜旅の棚卸しから、問いを掘る「つい語ってしまうこと」を掘り当て、自分だけの問いを1つに絞ります。
  2. 10/27（火）｜たった一人に向けて、問いを"学び"にする来てほしい具体的な人を思い浮かべ、その人のBefore→Afterを言葉にします。
  3. 11/10（火）｜学びの場を、設計する外部ゲストをお招きし、参加したくなる場の設計を学ぶ講義回です。
  4. 11/24（火）｜ミニ開催で、試作する（山場）各自が20分のミニ体験版を相互に開催し、5つの軸で相互に審査します。
  5. 別日程｜1対1で、企画を磨く（個別メンタリング）試作で受けたフィードバックをもとに、メンターと1対1で企画を詰めます。
  6. 12/8（火）｜自分の場に、人を集める◎ 今回ご登壇をお願いしている回です
    外部ゲストをお招きし、集客・告知・値づけ・動線を学ぶ講義回です。
  7. 12/22（火）｜ひらいて、送り出す（開業式）企画をお披露目し、初回開催日をその場でカレンダーに入れて修了します。

このゼミについて

POOLOは、旅を入り口に自分の生き方・働き方を問い直す大人の学び場として、7年以上続いてきました。卒業生は1,000名を超えます。

一方で、卒業後は学びを「受け取る側」で終わってしまう人がほとんどでした。このゼミは、そこを一歩進めるためのものです。旅の中で見つけたひとつの問いを、誰かが「参加したい」と思う小さな学びの場に変える。修了時には、参加費1〜3万円・全3〜5回の講座を自分でひらける状態になっていることをゴールにしています。

修了生が実際にゼミをひらき、そこに他の卒業生が参加者として集まる。「受講 → 開催 → 参加 → また受講」という循環を、コミュニティの中に立ち上げたいと考えています。
